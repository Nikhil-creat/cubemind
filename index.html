Learning path

  1. Learn the notation and turn each face until it feels natural.
  2. Solve the 2×2 with the layer method.
  3. Learn the beginner 3×3 method from the Guide tab.
  4. Practise with Learn mode, then time yourself.
  5. Move to 4×4 and 5×5 using reduction, then try Pyraminx and Skewb.

Notation and FAQ

Move notationU D L R F B are the top, bottom, left, right, front and back faces. A letter alone is a clockwise quarter turn looking at that face. A prime (R') is counter-clockwise. A 2 (R2) is a half turn. On big cubes, 2R turns the second layer from the right.
How does Learn mode work?Scramble, switch on Learn mode, and try to undo the scramble yourself with the move buttons or keys. The agent says whether each move was right, gives hints, or plays the next move for you.
Is the solver a full method solver?The Solve button and the agent undo your own scramble, which works on every cube size. For the real solving methods, follow the Guide tab step by step and ask the coach.
Is my API key safe?It is stored only in your browser and sent only to Groq or Anthropic. Use a key with a low spending limit.
